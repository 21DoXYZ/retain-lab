## Философия этого документа

**Вы не считаете смету вручную.** Claude AI сам раскладывает проект на слои (Frontend / Backend / Database / Infra), оценивает каждый компонент в днях и умножает на дневную ставку через `8-46-COST_CALCULATOR_PROMPT.md`.

Зачем тогда этот справочник?

1. **Валидация** — понять, правильно ли Claude разложил проект по слоям
2. **Корректировка** — если оценка в днях нереалистична, знать какие компоненты просить пересчитать
3. **Контроль распределения** — проверить, что доля Frontend/Backend/Database/Infra соответствует типу проекта
4. **Контроль ставки** — убедиться, что дневная ставка соответствует уровню AI-архитектора

**Правильный workflow:**
```
Вы → описываете проект (SPEC.md или бриф) + даёте свою дневную ставку
Claude → генерирует смету через COST_CALCULATOR_PROMPT
Вы → используете этот справочник чтобы валидировать результат
Claude → пересчитывает спорные компоненты
```

## Когда нужна смета (а не только КП)

- Проект стоит от 500K ₽ — клиент хочет видеть, за что платит
- Клиент выбирает между несколькими вариантами (Discovery / MVP / Full)
- Корпоративный клиент — нужна разбивка для согласования бюджета
- Клиент просит «расписать подробнее»

## Чек-лист валидации (после генерации)

Когда Claude вернул смету — пройдитесь по этому чек-листу. Если что-то не так, попросите Claude пересчитать конкретный слой.

- [ ] Сумма по слоям = итоговой стоимости (арифметика сходится)

- [ ] Есть сравнение с рынком (студия / фриланс / AI-разработка)

- [ ] Расходы на поддержку (хостинг, БД) посчитаны отдельно
- [ ] Нет двойного счёта: если Telegram-бот — в Backend, то его нет в Frontend

## Принципы оценки (как Claude считает)

### Как Claude разбивает проект

1. Берёт список модулей из SPEC.md / брифа (обычно 5-15)
2. Каждый модуль раскладывает на слои: Frontend, Backend, Database
3. Оценивает каждый компонент в днях (не в часах — проще валидировать)
4. Умножает дни на дневную ставку (которую вы задали)
5. Добавляет 15-20% на тестирование и полировку

Если Claude оценивает не так — попросите: "Раскладывай по слоям, каждый компонент в днях, добавь 15% на QA".

### Дневные ставки (ориентир, рынок РФ май 2026)

| Уровень | Ставка/день | Для каких проектов |
|---------|------------:|-------------------|
| Начинающий AI-архитектор | 12 000 — 20 000 ₽ | Лендинги, простые боты |
| Опытный AI-архитектор | 20 000 — 32 000 ₽ | SaaS MVP, сложные боты |
| Сеньор AI-архитектор | 32 000 — 52 000 ₽ | Enterprise, AI-экосистемы |

### Типичное распределение по слоям

| Слой | Доля в проекте |
|------|:--------------:|
| Frontend | 40-50% |
| Backend | 20-30% |
| Database | 5-10% |
| Инфра + тесты + документация | 15-25% |

```

  ↓ Список модулей, интеграций, количество таблиц БД

  ↓ См. таблицу выше (начинающий / опытный / сеньор)

  ↓ Загрузите:
  • 8-46-COST_CALCULATOR_PROMPT.md
  • Этот справочник (8-45) — как reference структуры
  • SPEC.md проекта
  
ШАГ 4: Промпт:
  "Составь смету по правилам из COST_CALCULATOR_PROMPT.
   Ставка: [X] ₽/день (см. таблицу выше — обычно 20 000-32 000 для middle).

ШАГ 5: Получите смету
  ↓ Claude вернёт разбивку по слоям + сводную таблицу + расходы

```
