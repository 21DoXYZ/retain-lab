# Чек-лист сборки: повтори AI-агента за 1 день

> Пошагово от нуля до работающего бота-агента «Финансовый директор». Отмечай галочками. Время — ориентир для одного человека. Используй вместе с артефактом «7 паттернов AI-агента» и кодом из репозитория урока.
>
> Стек: Node 20, TypeScript, Supabase, Anthropic. Нужен установленный Node 20+ и аккаунт Telegram.

---

## Этап 0 — Окружение (15 мин)

- [ ] Установлен Node.js 20 LTS (`node -v` → v20.x)
- [ ] Установлен Claude Code (рекомендуется — упрощает работу с Supabase MCP)
- [ ] Клонировал репозиторий: `git clone <repo> findirector && cd findirector`
- [ ] `npm install` прошёл без ошибок

---

## Этап 1 — Ключи и доступы (30 мин)

- [ ] **Telegram-бот:** [@BotFather](https://t.me/BotFather) → `/newbot` → сохранил `BOT_TOKEN`
- [ ] **Свой Telegram ID:** [@userinfobot](https://t.me/userinfobot) → `/start` → сохранил число (`OWNER_TELEGRAM_ID`)
- [ ] **Supabase:** создал проект на supabase.com → Settings → API → сохранил `SUPABASE_URL` и `service_role` ключ (НЕ anon!)
- [ ] **Anthropic:** console.anthropic.com → API Keys → создал `ANTHROPIC_API_KEY`, пополнил баланс
- [ ] (опц.) **Voyage AI:** dash.voyageai.com → `VOYAGE_API_KEY` (для долгой памяти)
- [ ] (опц.) **Deepgram:** console.deepgram.com → `DEEPGRAM_API_KEY` (для голоса)

🔴 `.env`-файлы создаёшь и хранишь сам, локально. Никогда не сливай их в чат Claude и не коммить в git.

---

## Этап 2 — Конфигурация (10 мин)

- [ ] `cp .env.example .env`
- [ ] Заполнил все обязательные переменные в `.env`
- [ ] `npm run typecheck` → 0 ошибок (проверка что env-схема и код согласованы)

## Этап 3 — База данных (30 мин)

- [ ] Применил миграции из `src/db/migrations/` по порядку (0001 → 0011)
  - через Supabase MCP в Claude Code: `apply_migration` для каждой
  - или вручную: Supabase Dashboard → SQL Editor → вставить содержимое каждого файла
- [ ] **Адаптировал seed под себя:**
  - [ ] миграция 0001 — свои `directions` (направления бизнеса) и `categories`
  - [ ] миграция 0002 — свои номера счетов + какой счёт привязан к Налоговому фонду
  - [ ] миграция 0008 — свой `telegram_id` владельца
- [ ] Проверил в Supabase: таблицы `transactions`, `directions`, `categories`, `funds`, `accounts` созданы
- [ ] Расширения включены: `vector`, `pg_trgm`, `pgcrypto` (Database → Extensions)

## Этап 5 — Проверка AI-агента (15 мин)

- [ ] Написал боту текстом: «сколько транзакций в базе?» → агент ответил (значит tool-use loop работает)

- [ ] (если есть Voyage) проверил долгую память: разметил контрагента → потом спросил про него

## Этап 7 — Адаптация под себя (дальше — сам)

Теперь это твой агент. Что менять:

- [ ] **Новый банк/источник** → добавь парсер в `src/parsers/` (см. как сделаны существующие)
- [ ] **Свои категории/направления** → правь seed или добавляй через SQL
- [ ] **Новый AI-инструмент** → опиши в `src/ai/tools.ts` + реализуй в `src/ai/toolHandlers.ts`
- [ ] **Изменить промпт агента** → `src/ai/prompts.ts`
- [ ] **Другая предметная область?** → артефакт «7 паттернов»: тот же скелет, другие функции

## Типичные ошибки

| Симптом | Причина | Решение |
|---|---|---|
| Бот не отвечает | Неверный `BOT_TOKEN` или `OWNER_TELEGRAM_ID` | Проверь `.env`, перезапусти |
| `409 Conflict` в логах | Два инстанса бота (локальный + прод) | Останови один |
| Выписка «не распознана» | Формат не поддержан | Проверь колонки в `detectSource()`, добавь парсер |
| AI «не отвечает» / висит | Нет баланса Anthropic или таймаут | Проверь баланс, логи `agent_logs.error` |
| Дубли транзакций | Сломан хеш-дедуп | Проверь `src/utils/hash.ts` |
| Память не ищет | Нет `VOYAGE_API_KEY` | Добавь ключ или работай без долгой памяти |
