# 9-50 | Контент-стратегия — Справочник структуры

> Reference-документ: что Claude генерирует для контент-стратегии личного бренда AI-архитектора.
> Используйте для валидации результата и формулирования требований — не для ручного заполнения.

> **Тип:** Reference
> **Фаза:** 9 — Маркетинг
> **Цель:** Справочник по 8 блокам контент-стратегии (позиционирование, аудитория, столпы, форматы, ритм, воронка, метрики)

---

## Философия этого документа

**Вы не пишете контент-стратегию вручную.** Claude AI генерирует её из вашего описания: кто вы, что продаёте, кому, какие ресурсы есть. Отдельного генератор-промпта нет — вы загружаете этот справочник + описание своего бренда напрямую в Claude.

Зачем тогда этот справочник?

1. **Валидация** — понять, правильно ли Claude построил все 8 блоков
2. **Корректировка** — если позиционирование размыто или столпы дублируют друг друга, знать что переделать
3. **Контроль структуры** — убедиться, что есть воронка «от контента до клиента», а не просто список постов
4. **Контроль KPI** — проверить, что метрики реалистичные и измеримые

**Правильный workflow:**
```
Вы → описываете: кто вы, что продаёте, аудитория, ресурсы, цель на 3 месяца
Claude → генерирует стратегию по 8 блокам (опираясь на этот справочник)
Вы → валидируете результат по чек-листу ниже
Claude → вносит правки
```

---

## Зачем нужен этот документ

Контент-стратегия — это **система**, а не список постов. Без неё контент превращается в хаотичный поток, который не ведёт к результату.

Формула:
```
Позиционирование → Аудитория → Столпы → Форматы → Ритм → Воронка → Метрики
```

Стратегия пишется **один раз на 3 месяца**, затем пересматривается по результатам метрик.

**Правило:** Если Claude не может описать аудиторию в одном предложении — попросите вернуться к позиционированию и переделать.

## Структура контент-стратегии: что Claude генерирует

Ниже — 8 блоков, которые Claude должен вернуть. Если какого-то блока нет или он заполнен абстракциями — попросите доработать.

### Блок 1: Позиционирование

```markdown
## Позиционирование

### Суть бренда (одно слово):
[Кем ты являешься для своей аудитории — Проводник / Практик / Наставник / Хакер]

### Формула позиционирования:
[Имя] — это [роль], который [что делает] для [кого] через [как].

### УТП (уникальное торговое предложение):
[1-2 предложения: почему идут именно к тебе, а не к конкурентам]

### Слоган:
[Короткая фраза, которая запоминается]

### Ключевые дифференциаторы:

| Конкуренты | Ты |
|-----------|-----|
| [Что делают другие] | [Что делаешь ты иначе] |
| [Слабость рынка] | [Твоя сила] |
| [Типичный подход] | [Твой уникальный подход] |
```

```markdown

- Желание: [Чего хотят достичь]
- Барьер: [Почему не делают сами]

### Вторичная (20% контента):
- Кто: [...]
- Боль: [...]
- Желание: [...]

### Третичная (10% контента):
- Кто: [...]
```

## Что Claude вернёт для AI-архитектора, запускающего Telegram-канал + Instagram

Ниже — пример того, что Claude сгенерирует, если загрузить этот справочник + описание: «Я фрилансер-AI-архитектор, запускаю личный бренд для привлечения клиентов на услуги AI-автоматизации и продвижения SaaS-продукта TaskFlow». Используйте как образец для сравнения со своим результатом.

### Контекст
Фрилансер-AI-архитектор **запускает личный бренд** для привлечения клиентов на услуги AI-автоматизации и продвижения SaaS-продукта TaskFlow.

### Позиционирование

**Суть бренда:** Практик

**Формула:** AI-архитектор, который строит реальные продукты на AI в российских реалиях — от идеи до работающего бизнеса — и показывает процесс открыто.

**УТП:** Я не программист, но у меня работающий SaaS-продукт и клиенты. Я показываю, как строить IT-бизнес с помощью AI, без кода и без иллюзий.

**Слоган:** «AI на практике. Бизнес без кода.»

### Целевая аудитория

**Первичная:** Предприниматели и владельцы малого бизнеса в РФ, которые хотят автоматизировать процессы с помощью AI, но не знают с чего начать.

**Вторичная:** Начинающие AI-энтузиасты, которые хотят монетизировать навыки работы с AI.

### Контентные столпы

| Столп | Доля | Описание |
|-------|------|----------|
| AI-разработка на практике | 35% | Кейсы сборки, spec-driven подход, инструменты |
| Автоматизация бизнеса | 25% | Как AI решает реальные задачи компаний |
| Запуск в РФ | 20% | Юридика, оплаты, 152-ФЗ, инфраструктура |
| Инструменты и лайфхаки | 15% | Обзоры, сравнения, неочевидные решения |
| Личность и миссия | 5% | Закулисье, ценности, личные истории |

### Форматы

**Instagram:** 3-4 Reels/нед + 2 карусели/нед
- Reels: говорящая голова + экранка, 30-90 сек, субтитры
- Карусели: чек-листы, до/после, цифры

**Telegram:** 5-7 постов/нед
- Пн — планы, Вт — кейс, Ср — закулисье, Чт — образование, Пт — итоги

### Воронка

```
Reels/Карусель (хук + ценность + CTA)
    → Кодовое слово в комментариях
    → Бот в Директе → ссылка на taskflow.ru
    → Бесплатный тариф → онбординг
    → Прогрев в Telegram-канале
    → Конверсия в платящего пользователя
```

|---------|---------|---------|---------|
| Reels | 12 | 14 | 16 |
| Охват Reels (средний) | 3K | 7K | 12K |

| ТГ-подписчики | 100 | 300 | 600 |
| Лиды | 20 | 50 | 100 |
| Платящие пользователи | 5 | 15 | 30 |

## Банк хуков по категориям

### Категория «Боль аудитории»
- «Ты тратишь [X часов] на [рутинный процесс]. Давай посчитаем.»
- «[Специалист] берёт [X тыс. руб.]. AI делает это за [Y минут]. Бесплатно.»
- «[Количество]% [процессов] — слепая зона. Вот почему.»

### Категория «Шок от простоты»
- «[Результат]. Один промпт. [Время].»
- «Я не написал ни строчки кода. Но у меня [результат].»
- «[Сложная задача] за [маленькое время]. Показываю как.»

### Категория «Провокация»
- «Тебе не нужен [специалист]. Тебе нужен промпт.»
- «[Распространённое мнение]? Давай разберём.»
- «[X]% людей говорят, что умеют [навык]. Реально умеют — [Y]%.»

### Категория «Цифры и факты»
- «[Срок] — от нуля до [результат]. Полный таймлайн.»
- «Мой стек на [сумма]/мес заменяет [что].»
- «ROI [X]%. Не шутка. Считаем на цифрах.»

## Чек-лист валидации (после генерации)

Когда Claude вернул стратегию — пройдитесь по этому чек-листу. Если что-то не так, попросите Claude переделать конкретный блок.

- [ ] Заполнено позиционирование (суть, формула, УТП, слоган)
- [ ] Описана целевая аудитория (первичная + вторичная)
- [ ] Определены 4-5 контентных столпов с процентным соотношением
- [ ] Сумма долей столпов = 100%
- [ ] Выбраны платформы и форматы
- [ ] Составлен недельный ритм публикаций
- [ ] Настроена воронка (от хука до конверсии)
- [ ] Зафиксированы KPI на 3 месяца — измеримые, не абстрактные
- [ ] Подготовлен банк хуков (20+ штук)
- [ ] Распределение 70/20/10 (ценность/продукт/личность) соблюдено

**Если найдена проблема — промпт для исправления:**
```
В стратегии проблема: [например, "столпы дублируют друг друга — 'AI-разработка' и 'инструменты' про одно"].
Перепиши только блок [X]. Сохрани остальные блоки без изменений.
```

## Workflow: как создать контент-стратегию за 15 минут

```
ШАГ 1: Сформулируйте вводные
  ↓ Кто вы, что продаёте, аудитория, ресурсы (платформы), цель на 90 дней
  
ШАГ 2: Откройте Claude AI (web)
  ↓ Загрузите:
  • Этот справочник (9-50) — как reference структуры
  • Описание своего бренда (1-2 абзаца)
  
ШАГ 3: Промпт:
  "Сгенерируй контент-стратегию по всем 8 блокам из 9-50.
   Вводные: [кто я, что продаю, аудитория, платформы, цель на 90 дней].
   Соблюдай 70/20/10. Включи банк хуков 20+ штук. Используй KPI, измеримые каждую неделю."
  
ШАГ 4: Получите результат
  ↓ Claude вернёт все 8 блоков + пример недельного ритма
  
ШАГ 5: Валидация (чек-лист выше)
  
ШАГ 6: Правки по конкретным блокам
  "Столп 3 слабый — нет конкретных тем. Добавь 10 примеров."
  
ШАГ 7: Скопируйте готовую стратегию в Notion / Obsidian
  ↓ Пересматривайте раз в месяц
```

---

*Стратегия пересматривается каждый месяц. Лучшие темы по охвату — масштабируются. Неудачные — заменяются. Воронка оптимизируется по конверсии на каждом этапе.*
