## Философия этого документа

**Вы не пишете Cookie Policy вручную.** Claude сам генерирует её из вашего описания проекта и списка используемых сторонних сервисов через `7-42-LEGAL_DOCS_GENERATOR_PROMPT.md`.

Зачем тогда этот справочник?

1. **Валидация** — понять, правильно ли Claude перечислил cookie и сторонние сервисы
2. **Корректировка** — если что-то не так, знать как попросить изменить
3. **Коммуникация** — говорить с Claude на языке "добавь Яндекс.Метрику в сторонние cookie" вместо "не хватает"
4. **Контроль качества** — проверить, что все реально используемые сервисы перечислены

**Правильный workflow:**
```
Вы → собираете список: какие cookie использует ваш сайт (auth, analytics,
      functional) и какие сторонние сервисы их ставят
Claude → генерирует Cookie Policy через Legal Docs Generator Prompt
Вы → используете этот справочник чтобы валидировать результат
Claude → вносит правки по вашим замечаниям
Вы → публикуете на /cookies + добавляете баннер
```

### Политика обработки файлов cookie

**{{PLATFORM_NAME}}**
*последнее обновление: {{UPDATE_DATE}}*

#### 1. Общие положения

1.1. Настоящая Политика обработки файлов cookie (далее — "Политика") описывает, каким образом платформа {{PLATFORM_NAME}} (далее — "Платформа"), доступная по адресу {{PLATFORM_URL}}, использует файлы cookie и аналогичные технологии.

1.2. Используя Платформу, вы соглашаетесь с использованием файлов cookie в соответствии с настоящей Политикой.

#### 2. Что такое файлы cookie

2.1. Файлы cookie — это небольшие текстовые файлы, которые сохраняются на вашем устройстве при посещении Платформы. Они позволяют Платформе запоминать ваши предпочтения, обеспечивать корректную работу функций и улучшать пользовательский опыт.

#### 3. Какие файлы cookie мы используем

3.1. **Строго необходимые (essential cookies)**
Обеспечивают базовую функциональность Платформы: авторизацию, безопасность сессий, защиту от CSRF-атак. Без этих cookie Платформа не может работать корректно. Отключить их нельзя.

3.2. **Функциональные (functional cookies)**
Запоминают ваши предпочтения: язык интерфейса, настройки отображения, выбранные фильтры. Помогают обеспечить удобство использования.

3.3. **Аналитические (analytics cookies)**
Помогают нам понять, как пользователи взаимодействуют с Платформой: какие страницы посещают, сколько времени проводят, с какими функциями работают.

#### 4. Сторонние файлы cookie

4.1. Платформа может использовать файлы cookie от следующих сторонних сервисов:

| Сервис | Назначение | Тип |
|--------|-----------|-----|
| Supabase Auth | Аутентификация и управление сессиями | Необходимые |
| Vercel Analytics | Анализ производительности | Аналитические |

> **Примечание:** Обновите таблицу в соответствии с сервисами, используемыми в вашем проекте.

#### 5. Управление файлами cookie

5.1. При первом посещении Платформы вам будет предложено принять или настроить использование файлов cookie через информационный баннер.

5.2. Вы можете в любое время изменить настройки cookie в своём браузере:
- **Chrome:** Настройки → Конфиденциальность и безопасность → Файлы cookie
- **Firefox:** Настройки → Приватность и защита → Куки
- **Safari:** Настройки → Конфиденциальность → Файлы cookie

5.3. Обратите внимание: отключение необходимых cookie может привести к невозможности использования некоторых функций Платформы.

#### 6. Срок хранения

| Тип cookie | Срок хранения |
|------------|---------------|
| Необходимые | Сессия или до 30 дней |
| Функциональные | До 1 года |
| Аналитические | До 2 лет |

#### 7. Изменения в Политике

7.1. Мы можем обновлять настоящую Политику. Обновлённая версия будет размещена на Платформе с указанием даты последнего обновления.

#### 8. Контакты

По вопросам, связанным с использованием файлов cookie, свяжитесь с нами:
Email: {{CONTACT_EMAIL}}

## Чек-лист валидации (после генерации)

Когда Claude сгенерировал политику cookie — пройдитесь по этому чек-листу.

```
[ ] 1. Название и URL платформы подставлены
[ ] 2. Нет placeholder'ов {{...}}
[ ] 3. Перечислены все реально используемые сторонние сервисы
     (Supabase, Яндекс.Метрика, Vercel Analytics, и т.д.)
[ ] 4. Для каждого сервиса указан тип cookie (необходимые / аналитические / функциональные)
[ ] 5. Указаны сроки хранения для каждого типа
[ ] 6. Есть ссылка на инструкции управления cookie в браузерах
[ ] 7. Указан контактный email
[ ] 8. Дата обновления проставлена
```

**Если найдена проблема — промпт для исправления:**
```
В сгенерированной Cookie Policy проблема: [что не так].
Добавь [сервис X] в таблицу сторонних cookie с правильным типом.
```

## Cookie-баннер — текст и код

### Текст баннера

```
Мы используем файлы cookie для обеспечения работы Платформы
и улучшения пользовательского опыта. Продолжая использовать сайт,
вы соглашаетесь с Политикой cookie и Политикой конфиденциальности.

[Принять] [Настроить]
```

### React-компонент баннера (пример)

```tsx
'use client';

import { useState, useEffect } from 'react';

export function CookieBanner() {
  const [visible, setVisible] = useState(false);

  useEffect(() => {
    const consent = localStorage.getItem('cookie-consent');
    if (!consent) setVisible(true);
  }, []);

  const accept = () => {
    localStorage.setItem('cookie-consent', 'accepted');
    setVisible(false);
  };

  if (!visible) return null;

  return (
    <div className="fixed bottom-0 left-0 right-0 bg-background border-t p-4 z-50">
      <div className="container flex items-center justify-between gap-4">
        <p className="text-sm text-muted-foreground">
          Мы используем файлы cookie для обеспечения работы платформы.{' '}
          <a href="/cookies" className="underline">Подробнее</a>
        </p>
        <button
          onClick={accept}
          className="bg-primary text-primary-foreground px-4 py-2 rounded text-sm"
        >
          Принять
        </button>
      </div>
    </div>
  );
}
```

```
ШАГ 1: Соберите список cookie и сторонних сервисов
  ↓ Какие auth-cookie? Какая аналитика? Какие функциональные?

  ↓ Загрузите:
  • Список cookie и сервисов
  • 7-42-LEGAL_DOCS_GENERATOR_PROMPT.md (из toolkit)
  
ШАГ 3: Промпт:
  "Сгенерируй политику cookie для этого проекта по инструкциям
   из Legal Docs Generator Prompt. Учти все сторонние сервисы из списка."
  
ШАГ 4: Валидация (этот документ)
  ↓ Пройдитесь по чек-листу выше

```

**Итог:** вы не написали политику cookie вручную — собрали список сервисов, валидировали результат.
