# 10-55 | SaaS бизнес-модель — Справочник структуры

> Reference-документ: что Claude генерирует для бизнес-модели SaaS-продукта.
> Используйте для валидации результата и формулирования требований — не для ручного заполнения.

> **Тип:** Reference
> **Фаза:** 10 — Масштабирование
> **Цель:** Справочник по 6 блокам SaaS-модели (проблема, решение, аудитория, доход, юнит-экономика, конкуренты)

---

## Философия этого документа

**Вы не пишете бизнес-модель вручную.** Claude AI генерирует её из вашей идеи продукта (1-2 абзаца), опираясь на этот справочник. Отдельного генератор-промпта нет — вы загружаете этот документ + описание идеи в Claude.

Зачем тогда этот справочник?

1. **Валидация** — проверить, что Claude посчитал юнит-экономику и она сходится (LTV/CAC > 3, точка безубыточности рассчитана)
2. **Корректировка** — если тарифы не обоснованы или ICP размыт, знать что попросить переделать
3. **Контроль полноты** — убедиться, что все 6 блоков заполнены и присутствует Moat
4. **Экономика** — проверить арифметику: ARPU × активные = MRR, расходы < MRR через 3-6 месяцев

**Правильный workflow:**
```
Вы → описываете идею продукта (2-3 абзаца: проблема, решение, аудитория)
Claude → генерирует полную бизнес-модель по 6 блокам + юнит-экономику + сценарий на 12 месяцев
Вы → валидируете арифметику и тарифы по чек-листу ниже
Claude → пересчитывает спорные блоки
```

---

## Зачем нужен этот документ

SaaS (Software as a Service) — это бизнес-модель, где пользователь платит за доступ к программному продукту по подписке. Для AI-архитектора это основной путь к масштабируемому доходу.

Формула SaaS-бизнеса:
```
Проблема → Решение (продукт) → Монетизация (подписка) → Масштабирование (рост MRR)
```

**Правило:** Если ты не можешь описать, почему клиент будет платить каждый месяц (а не один раз) — у тебя нет SaaS-модели.

## Что Claude вернёт для TaskFlow

Ниже — пример того, что Claude сгенерирует, если загрузить этот справочник + описание: «AI-трекер задач для фрилансеров с интеграцией Telegram, автоматической приоритизацией и отчётами для клиентов». Используйте как образец для сравнения со своим результатом.

### Проблема

Фрилансеры с 3+ проектами одновременно теряют задачи, забывают дедлайны и тратят 5-7 часов в неделю на организацию работы. Существующие трекеры (Notion, Trello, Asana) заточены под команды, а не под соло-специалистов.

Цена проблемы: 25-30 часов/мес при ставке 2000 руб/час = 50-60 тыс. руб. потерянного дохода.

### Решение

**TaskFlow** — AI-трекер задач для фрилансеров, который автоматически собирает задачи из мессенджеров, приоритизирует их через AI и генерирует отчёты для клиентов.

Ключевые функции:
1. AI-приоритизация → каждое утро список «что делать первым»
2. Интеграция с Telegram → задачи извлекаются из чатов автоматически
3. Автоматические напоминания → за 24ч и за 2ч до дедлайна
4. Отчёты для клиентов → генерация за 10 секунд вместо 20 минут
5. Аналитика продуктивности → понимание, куда уходит время

### Целевая аудитория

**ICP:** Фрилансер-дизайнер / разработчик / копирайтер, 25-40 лет, ведёт 3-7 проектов одновременно, доход 100-300 тыс. руб/мес, использует Telegram как основной рабочий мессенджер. Триггер покупки: потерял задачу клиента или пропустил дедлайн.

### Тарифная сетка

| Параметр | Free | Pro | Business |
|----------|------|-----|----------|
| **Цена** | 0 руб/мес | 990 руб/мес | 4 990 руб/мес |
| **Целевой пользователь** | Пробует продукт | Активный фрилансер | Фрилансер-агентство |
| **Проекты** | до 3 | до 15 | Безлимит |
| **AI-приоритизация** | Базовая (1 раз/день) | Полная (реалтайм) | Полная + командная |
| **Интеграция Telegram** | 1 чат | 10 чатов | Безлимит |
| **Отчёты для клиентов** | — | Да (шаблонные) | Да + свой брендинг |
| **Аналитика** | — | Базовая | Полная + экспорт |
| **API-доступ** | — | — | Да |
| **Поддержка** | FAQ | Telegram-чат | Приоритетная |

**Почему эти цены:**
- Free → Pro: порог 3 проекта = точка, где фрилансер начинает терять задачи
- Pro (990 руб) = 0.5-1% от дохода фрилансера. Окупается за 30 минут сэкономленного времени
- Business (4990 руб) = для тех, кто масштабируется и берёт субподрядчиков

### Юнит-экономика

| Метрика | Значение |
|---------|----------|
| ARPU | 1 500 руб/мес (среднее Free+Pro+Business) |
| CAC | 2 000 руб (контент-маркетинг + холодные сообщения) |
| LTV | 18 000 руб (12 мес средний срок жизни) |
| LTV/CAC | 9.0 (отлично, цель > 3) |
| Churn Rate | 7% в месяц |
| Payback Period | 1.3 мес |

**Расходы (ежемесячные):**

| Статья | Сумма |
|--------|-------|
| Vercel (Pro) | 1 500 руб |
| Beget VPS | 800 руб |
| Supabase (Pro) | 2 000 руб |
| Claude API | 3 000 руб |
| ЮKassa (3.5%) | от оборота |
| Домен + SSL | 100 руб |
| **ИТОГО фиксированные** | ~7 400 руб/мес |

**Точка безубыточности:** 7 400 / 1 500 = 5 платящих пользователей

**Сценарий роста:**

| Месяц | Новые | Отток | Платящие | MRR | Прибыль |
|-------|-------|-------|----------|-----|---------|
| 1 | 10 | 0 | 5 | 7 500 | ~100 руб |
| 3 | 15 | 3 | 22 | 33 000 | ~25 600 |
| 6 | 20 | 5 | 55 | 82 500 | ~75 100 |
| 12 | 25 | 8 | 120 | 180 000 | ~172 600 |

### Конкурентное преимущество

| Конкурент | Цена | Минус для фрилансера |
|-----------|------|-----------------------|
| Notion | бесплатно | Нет AI-приоритизации, нужно настраивать самому |
| Trello | 800 руб/мес | Заточен под команды, нет Telegram-интеграции |
| Asana | 1200 руб/мес | Избыточный для одного человека |
| Персональный ассистент | 40 000+ руб/мес | Дорого, зависимость от человека |

**Moat (защита от копирования):**
1. AI-модель, обученная на паттернах фрилансеров (чем больше данных, тем точнее)
2. Глубокая интеграция с Telegram (основной мессенджер для фрилансеров в РФ)
3. Локализация: ЮKassa, 152-ФЗ, серверы в РФ
4. Community: Telegram-сообщество пользователей → сетевой эффект

## Чек-лист валидации (после генерации)

Когда Claude вернул бизнес-модель — пройдитесь по этому чек-листу. Если что-то не так, попросите Claude пересчитать конкретный блок.

- [ ] Проблема описана конкретно (с ценой в деньгах/часах)
- [ ] Решение — 3-5 функций (не 20)
- [ ] ICP описан до конкретной роли и триггера покупки
- [ ] Тарифы: Free → Pro → Business с чёткой градацией
- [ ] Цены обоснованы (якорение + % от дохода клиента)
- [ ] LTV/CAC > 3 (критично)
- [ ] Точка безубыточности рассчитана и указана в пользователях
- [ ] Конкуренты проанализированы (минимум 3)
- [ ] Moat описан (почему не скопируют)
- [ ] Сценарий на 12 месяцев реалистичен (не «в месяц 1000 новых»)
- [ ] Расходы покрывают всё: хостинг, БД, AI API, платежи, маркетинг

**Если найдена проблема — промпт для исправления:**
```
В модели проблема: [например, "LTV/CAC = 1.5, это ниже порога"].
Пересчитай: либо снизь CAC (какие каналы?), либо подними ARPU (апсейл?),
либо увеличь срок жизни клиента (снижение churn — как?).
```

## Workflow: как создать SaaS-модель за 15 минут

```
ШАГ 1: Сформулируйте идею в 2-3 абзацах
  ↓ Проблема, кому больно, как решаете, почему через подписку
  
ШАГ 2: Откройте Claude AI (web)
  ↓ Загрузите:
  • Этот справочник (10-55)
  • Описание своей идеи
  
ШАГ 3: Промпт:
  "Сгенерируй полную SaaS бизнес-модель по 6 блокам из 10-55.
   Вводные: [моя идея]. Посчитай юнит-экономику, тарифную сетку Free/Pro/Business,
   сценарий на 12 месяцев, расходы, точку безубыточности, Moat."
  
ШАГ 4: Получите результат
  ↓ Claude вернёт все 6 блоков + таблицы + расчёты
  
ШАГ 5: Валидация арифметики
  ↓ Проверьте LTV/CAC > 3, сумма расходов, точка безубыточности
  
ШАГ 6: Если что-то не сходится — попросите пересчитать
  "LTV/CAC получился 1.8. Что можно оптимизировать?"
  
ШАГ 7: Скопируйте в Notion / Obsidian как рабочий документ
```

**Итог:** модель готова без финансовой модели в Excel. Claude посчитал, вы проверили арифметику.

---

*SaaS-бизнес — это марафон, не спринт. Первые 3 месяца — валидация (10-30 клиентов). Следующие 3 — оптимизация (снижение churn, рост ARPU). После — масштабирование (рост CAC-каналов).*
