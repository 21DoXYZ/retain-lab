## Зачем нужен этот документ

Лендинг — это **продавец, который работает 24/7**. Но 80% лендингов не конвертируют, потому что:
- Копирайтинг про продукт, а не про клиента
- Нет чёткой структуры «боль → решение → доказательство»
- CTA размытый или отсутствует

Методология VORTEX + Hormozi решает это:

```
V — Value (ценность): что клиент получает
O — Outcome (результат): конкретный измеримый итог
R — Risk Reversal (снятие рисков): гарантии, бесплатный период
T — Time (время): как быстро получит результат
E — Effort (усилия): насколько это просто
X — eXclusivity (эксклюзивность): почему только здесь
```

**Правило:** Каждый блок лендинга отвечает на один вопрос клиента. Если блок не отвечает ни на что — удали его.

## Методология

### VORTEX-формула (для каждого блока):
- Value: какую ценность получает клиент
- Outcome: конкретный измеримый результат
- Risk Reversal: как снимаем страх/риск
- Time: сколько времени до результата
- Effort: сколько усилий от клиента
- eXclusivity: чем это уникально

### Структура лендинга (8 обязательных блоков):

**Блок 1: HERO (первый экран)**
- Заголовок: главная ценность продукта (не фича, а результат)
- Подзаголовок: для кого и что конкретно получит
- CTA-кнопка: конкретное действие
- Social proof: одна строка (X клиентов / рейтинг / факт)

**Блок 2: PAIN (боль)**
- 3-5 конкретных болей целевой аудитории
- Формат: "Знакомо?" — описание ситуации
- Цена проблемы в деньгах/времени

**Блок 3: SOLUTION (решение)**
- Как продукт решает каждую боль
- 3-5 ключевых функций с результатами (не фичи!)
- Визуальная схема: было → стало

**Блок 4: HOW IT WORKS (как это работает)**
- 3-4 простых шага
- Формат: "Шаг 1 → Шаг 2 → Шаг 3 → Результат"
- Акцент на простоту (Effort из VORTEX)

**Блок 5: PROOF (доказательства)**
- 2-3 кейса / отзыва / цифры
- Формат: "До: [проблема] → После: [результат]"
- Конкретные цифры, не абстракции

**Блок 6: PRICING (тарифы)**
- 2-3 тарифа с чёткой градацией
- Сравнительная таблица "что включено"
- Якорение: сравнение со стоимостью альтернативы
- Risk Reversal: бесплатный период / гарантия возврата

**Блок 7: FAQ (частые вопросы)**
- 5-7 вопросов, которые снимают возражения
- Каждый ответ = снятие конкретного страха
- Последний вопрос = мягкий CTA

**Блок 8: FINAL CTA (финальный призыв)**
- Повтор главного заголовка (другими словами)
- Urgency/Scarcity (если уместно)
- CTA-кнопка + безрисковое предложение

## Правила копирайтинга:
1. Пиши от второго лица ("вы получите", не "мы предлагаем")
2. Каждый заголовок — про результат, не про фичу
3. Конкретные цифры > абстрактные обещания
4. Один CTA на весь лендинг (одно действие)
5. Язык клиента, не технический жаргон
6. Короткие предложения. Короткие абзацы.

## Чек-лист готового лендинга

### Копирайтинг:
- [ ] Заголовок Hero — про результат, не про фичу
- [ ] Боли — конкретные ситуации, не абстрактные
- [ ] Цена проблемы — в деньгах или часах
- [ ] Решение — «было → стало», не список функций
- [ ] Шаги — не больше 3-4, максимально простые
- [ ] Доказательства — конкретные цифры, не «многие клиенты»
- [ ] Тарифы — якорение со стоимостью альтернативы
- [ ] FAQ — каждый вопрос снимает конкретное возражение
- [ ] CTA — одно действие, повторяется 3-4 раза по странице

### Технические элементы:
- [ ] Мобильная версия — 70%+ трафика с телефона
- [ ] Скорость загрузки — менее 3 секунд
- [ ] Формы — минимум полей (имя + email или Telegram)
- [ ] Метрика / аналитика — подключены цели
- [ ] Юридика — политика конфиденциальности, чекбокс ПД
