# 10-57 | Дорожная карта масштабирования — Справочник структуры

> Reference-документ: 4 эталонных 90-дневных плана (Фрилансер / Агентство / SaaS / Трудоустройство), которые Claude использует как базу для персонализации под ваш текущий статус.
> Используйте для валидации сгенерированного плана — не для ручного заполнения.

> **Тип:** Reference
> **Фаза:** 10 — Масштабирование
> **Цель:** Персональная дорожная карта развития AI-архитектора на 30-60-90 дней с тремя путями — с KPI, вехами и чекпоинтами

---

## Философия этого документа

**Вы не пишете дорожную карту вручную.** Claude AI генерирует персонализированный план из вашего текущего статуса (что уже есть: кейсы, доход, аудитория) и выбранной цели, опираясь на 3 эталонных пути в этом справочнике.

Зачем тогда этот справочник?

1. **Эталоны** — Claude использует 4 путевых шаблона (Фрилансер / Агентство / SaaS / Трудоустройство) как базу
2. **Валидация** — проверить, что KPI и вехи реалистичны для вашего уровня
3. **Корректировка** — если план слишком амбициозный или наоборот, знать какую неделю попросить пересчитать
4. **Сравнение** — понять, какой путь вам подходит (таблица сравнения в конце)

**Правильный workflow:**
```
Вы → описываете текущий статус (что есть: кейсы, доход, аудитория, время в день)
      + выбираете путь (Фрилансер / Агентство / SaaS / Трудоустройство / Комбинированный)
      + формулируете цель на 90 дней
Claude → генерирует персональный план, опираясь на эталоны из этого справочника
Вы → валидируете реалистичность KPI и вех
Claude → корректирует спорные недели
```

---

## Зачем нужен этот документ

После окончания курса наступает самый сложный момент: что делать дальше? Без плана выпускник теряет 1-2 месяца на «поиск себя».

Этот шаблон решает проблему: **конкретный план на 90 дней с измеримыми результатами**.

Четыре пути — четыре разных стратегии:

```
Путь 1: Фрилансер     → 3-5 проектов/мес            → 150-300K руб/мес
Путь 2: Агентство     → команда 2-5 человек         → 500K-1.5M руб/мес
Путь 3: SaaS          → продукт с подпиской         → 50-150K MRR
Путь 4: Трудоустройство → in-house позиция в IT      → 130-700K руб/мес (по уровню)
```

**Правило:** Выбери один основной путь. Можно комбинировать (in-house + фриланс на стороне), но фокус должен быть один. Распыление — главная причина провала.

---

## Как пользоваться справочником

1. Прочитайте описание всех четырёх путей
2. Выберите основной (по ресурсам, характеру, целям)
3. Опишите Claude свой текущий статус + выбранный путь + цель на 90 дней
4. Claude сгенерирует персональный план
5. Валидируйте по чек-листу в конце документа
6. Каждую неделю — чекпоинт (30 минут самоанализа)

## Эталон Пути 1: Фрилансер (проектная работа)

### Для кого:
- Хочешь быстро начать зарабатывать
- Предпочитаешь работать один
- Нет стартового капитала
- Хочешь набрать портфолио и кейсы

### 30-60-90 план

#### Дни 1-30: «Запуск и первые деньги»

**Цель:** 2-3 оплаченных проекта, стабильный поток заявок.

| Неделя | Задачи | KPI |
|--------|--------|-----|
| 1 | Создать портфолио (3 кейса из курса). Оформить Telegram-канал и профиль в LinkedIn. Написать 30 холодных сообщений. | 30 сообщений, 1 канал |
| 2 | Отправить ещё 50 холодных сообщений. Публиковать 3-5 постов в ТГ. Провести 2-3 discovery-звонка. | 5 ответов, 2 звонка |
| 3 | Закрыть первый проект (даже за минимальную сумму). Снять Reels о процессе. Собрать отзыв. | 1 оплаченный проект |
| 4 | Оптимизировать outreach (какие сообщения работают). Начать второй проект. Создать шаблон предложения. | 2 проекта в работе |

**KPI на конец месяца:**
- [ ] 2+ оплаченных проекта
- [ ] 3+ кейса в портфолио
- [ ] 80+ холодных сообщений отправлено
- [ ] 5+ discovery-звонков проведено
- [ ] Telegram-канал: 50+ подписчиков

**Вехи (milestones):**
- Первый оплаченный проект
- Первый отзыв от клиента
- Первый входящий лид (клиент сам нашёл)

---

#### Дни 31-60: «Стабилизация и рост»

**Цель:** 3-4 проекта/мес, средний чек 50-80K руб.

| Неделя | Задачи | KPI |
|--------|--------|-----|
| 5 | Повысить чек на 20-30%. Настроить шаблоны (предложение, договор, ТЗ). Автоматизировать часть outreach. | Средний чек 50K+ |
| 6 | Выбрать нишу (специализация): рестораны / образование / e-commerce / ... Адаптировать портфолио под нишу. | 1 выбранная ниша |
| 7 | Публиковать 5+ постов/нед в ТГ. Снимать 2-3 Reels/нед. Начать получать входящие заявки. | 2+ входящих лида |
| 8 | Создать пакетные предложения (3 пакета: базовый / стандарт / премиум). Закрыть 3-4 проекта за месяц. | 3 проекта, 150K+ доход |

**KPI на конец месяца:**
- [ ] 3+ проектов завершено
- [ ] Средний чек 50K+ руб
- [ ] Доход 150K+ руб за месяц
- [ ] 3+ входящих лида (органика)
- [ ] Telegram-канал: 150+ подписчиков

**Вехи:**
- Выбрана специализация (ниша)
- Средний чек вырос на 30%+
- Первый клиент по рекомендации

---

#### Дни 61-90: «Масштабирование»

**Цель:** 4-5 проектов/мес, средний чек 70-100K руб, 300K+ доход.

| Неделя | Задачи | KPI |
|--------|--------|-----|
| 9 | Создать систему: CRM (хотя бы Notion), воронка лидов, шаблоны процессов. | CRM настроена |
| 10 | Рассмотреть возможность делегирования (помощник / субподрядчик на часть задач). | 1 задача делегирована |
| 11 | Создать продукт-триггер: бесплатный аудит / чек-лист / мини-курс → генерация лидов. | 1 лид-магнит |
| 12 | Планирование следующего квартала: оставаться фрилансером → переход в агентство / SaaS. | План на Q2 |

**KPI на конец месяца:**
- [ ] 4+ проектов завершено
- [ ] Средний чек 70K+ руб
- [ ] Доход 300K+ руб за месяц
- [ ] 50% лидов — входящие (не холодные)
- [ ] Принято решение о следующем шаге (агентство / SaaS / продолжить фриланс)

## Эталон Пути 2: Агентство (команда)

### Для кого:
- Умеешь управлять людьми и процессами
- Хочешь масштабировать доход выше 300K/мес
- Готов инвестировать время в построение команды
- Есть 2-3 стабильных клиента для старта

### 30-60-90 план

#### Дни 1-30: «Соло-агентство»

**Цель:** Выстроить процессы, которые можно передать другому.

| Неделя | Задачи | KPI |
|--------|--------|-----|
| 1 | Определить 3 услуги агентства (например: AI-боты, автоматизация, аналитика). Оформить предложения. | 3 пакета услуг |
| 2 | Создать операционные шаблоны: бриф клиента, ТЗ, этапы проекта, чек-листы качества. | 5 шаблонов |
| 3 | Закрыть 2-3 проекта по новым процессам. Замерить время на каждый этап. | 2 проекта, хронометраж |
| 4 | Найти первого субподрядчика / ассистента. Делегировать 1 задачу (например, лендинги). | 1 человек, 1 задача |

**KPI на конец месяца:**
- [ ] 3+ услуги описаны и упакованы
- [ ] 5+ операционных шаблонов
- [ ] 1 человек в команде (субподрядчик)
- [ ] 2+ проектов завершено через стандартизированный процесс
- [ ] Юридика: ИП / ООО, договоры, акты

---

#### Дни 31-60: «Первая команда»

**Цель:** Команда 2-3 человека, 5+ проектов в месяц.

| Неделя | Задачи | KPI |
|--------|--------|-----|
| 5 | Нанять/привлечь второго специалиста. Разделить роли: ты = продажи + архитектура, команда = реализация. | 2 человека |
| 6 | Настроить систему управления: Telegram-канал команды + Notion/TaskFlow для задач. | Система управления |
| 7 | Масштабировать привлечение: контент + outreach + партнёрства. | 10+ лидов/мес |
| 8 | Поднять чек: средний проект 100K+ руб. Добавить ежемесячное обслуживание (retainer). | Чек 100K+, 1 retainer |

**KPI на конец месяца:**
- [ ] 3+ человека в команде (включая тебя)
- [ ] 5+ проектов/мес
- [ ] Средний чек 100K+ руб
- [ ] 1+ клиент на ежемесячном обслуживании
- [ ] Оборот 500K+ руб/мес

---

#### Дни 61-90: «Систематизация»

**Цель:** Агентство работает без твоего участия в каждом проекте.

| Неделя | Задачи | KPI |
|--------|--------|-----|
| 9 | Нанять проектного менеджера (или обучить одного из команды). | 1 PM |
| 10 | Запустить маркетинг агентства: сайт, кейсы, Telegram-канал бренда. | Сайт + 5 кейсов |
| 11 | Стандартизировать качество: code review, тестирование, чек-листы приёмки. | QA-процесс |
| 12 | Запустить реферальную программу для клиентов. Планировать Q2. | Реферальная программа |

**KPI на конец месяца:**
- [ ] 4-5 человек в команде
- [ ] 7+ проектов/мес
- [ ] Ты не участвуешь в каждом проекте лично
- [ ] Оборот 800K-1.5M руб/мес
- [ ] 3+ клиентов на ежемесячном обслуживании

## Эталон Пути 3: SaaS (продукт)

### Для кого:
- Хочешь построить масштабируемый бизнес
- Готов 2-3 месяца инвестировать без дохода
- Есть идея продукта, подтверждённая спросом
- Цель: пассивный / полупассивный доход

### 30-60-90 план

#### Дни 1-30: «MVP и первые пользователи»

**Цель:** Работающий MVP, 10-20 пользователей, 3-5 платящих.

| Неделя | Задачи | KPI |
|--------|--------|-----|
| 1 | Валидация идеи (5 интервью). PROJECT_IDEA.md. Анализ конкурентов. | 5 интервью, идея описана |
| 2 | SPEC.md. Настройка Claude Code. Начало сборки MVP. | Спецификация готова |
| 3 | Завершение MVP. Лендинг. Подключение ЮKassa. Деплой. | MVP задеплоен |
| 4 | Привлечение первых 10 пользователей. Сбор фидбека. Итерация. | 10 пользователей, 3 платящих |

**KPI на конец месяца:**
- [ ] MVP запущен и доступен
- [ ] 10+ зарегистрированных пользователей
- [ ] 3+ платящих пользователей
- [ ] Обратная связь собрана от 5+ пользователей
- [ ] MRR > 0 руб (любая сумма)

---

#### Дни 31-60: «Product-Market Fit»

**Цель:** 30-50 пользователей, подтверждённый спрос, понятная экономика.

| Неделя | Задачи | KPI |
|--------|--------|-----|
| 5 | Итерация продукта по фидбеку. Фикс топ-3 проблем. Добавление 1-2 запрошенных функций. | Churn < 10% |
| 6 | Запуск контент-маркетинга: Telegram-канал, 3 Reels/нед. | 100 подписчиков ТГ |
| 7 | Настройка аналитики: воронка, retention, churn. A/B тест тарифов. | Аналитика работает |
| 8 | Холодный outreach: 100+ сообщений для ЦА. Партнёрства. | 20+ новых пользователей |

**KPI на конец месяца:**
- [ ] 30+ активных пользователей
- [ ] 10+ платящих
- [ ] Churn < 10%/мес
- [ ] MRR 15K-50K руб
- [ ] NPS > 7 (готовы рекомендовать)

---

#### Дни 61-90: «Рост»

**Цель:** 100+ пользователей, устойчивый рост, MRR 50-150K руб.

| Неделя | Задачи | KPI |
|--------|--------|-----|
| 9 | Масштабирование привлечения: автоматизация outreach, реферальная программа. | 30+ новых/мес |
| 10 | Оптимизация онбординга: welcome-серия, туториалы, чат поддержки. | Retention +20% |
| 11 | Добавление Premium-функций. Рост ARPU через upsell. | ARPU +15% |
| 12 | Планирование: нанять первого человека? Привлечь инвестиции? Продолжить solo? | Стратегия Q2 |

**KPI на конец месяца:**
- [ ] 100+ зарегистрированных пользователей
- [ ] 30+ платящих
- [ ] MRR 50K-150K руб
- [ ] Churn < 7%/мес
- [ ] LTV/CAC > 3
- [ ] Стратегия на следующие 3 месяца определена

## Эталон Пути 4: Трудоустройство (in-house позиция)

### Для кого:
- Хочешь стабильную зарплату и социальный пакет
- Не готов к рискам предпринимательства
- Нужны "старшие коллеги", чтобы расти быстрее
- Хочешь работать в большой команде над сложным продуктом
- Релокация / визовая поддержка от работодателя

### Куда устраиваться (Россия)

**Где искать:**
- **HeadHunter (hh.ru)** — главный портал, фильтр "удалёнка" работает
- **Хабр Карьера (career.habr.com)** — IT-специфика, IT-зарплаты выше среднего
- **GetMatch, Geekjob** — для middle/senior разработчиков
- **Telegram-каналы:** @forallhr, @g_jobbot, @hwfo (вакансии в IT)
- **LinkedIn** (с VPN) — для международных позиций и стартапов
- **Прямой outreach** — писать CTO/основателям AI-стартапов

### 5 позиций, на которые подходит выпускник курса

#### 1. AI-инженер / ML-инженер

**Что делает:** Внедряет AI в продукт компании. Интеграция Claude/GPT API, проектирование RAG-систем, file-based и DB-based knowledge bases, prompt engineering, AI-агенты для production.

**Зарплата (РФ, нетто, удалёнка):**
- Junior: 80-150K руб/мес
- Middle: 150-280K руб/мес
- Senior: 280-500K руб/мес
- Lead: 500K-800K+ руб/мес

**Что нужно из курса:**
- Все навыки промпт-инжиниринга и работы с Claude API
- Tool Use, RAG-пайплайны, AI-агенты
- Кейсы из портфолио (AI-чат, AI-аналитика)

**Где есть вакансии:** Яндекс, Сбер, Тинькофф, VK, Avito, Wildberries, AI-стартапы

---

#### 2. AI-архитектор / Solution Architect (AI)

**Что делает:** Проектирует AI-системы на уровне всего продукта. Выбирает модели, архитектуры, интеграции. Управляет AI-командой. Общается с бизнесом и переводит требования в техзадания.

**Зарплата (РФ, нетто, удалёнка):**
- Middle: 250-400K руб/мес
- Senior: 400-700K руб/мес
- Lead/Principal: 700K-1.2M руб/мес

**Что нужно из курса:**
- Spec-First методология (главное!)
- Архитектура субагентов и AI-систем
- Опыт с production AI (не только хеллоу-ворлд)
- Soft skills: коммуникация с бизнесом

**Где есть вакансии:** крупные tech-компании, банки (Сбер, Тинькофф, Альфа), консалтинг (Accenture, EPAM)

---

#### 3. Full-Stack разработчик (с AI-уклоном)

**Что делает:** Пишет fullstack-приложения от БД до фронта. Знает Next.js, Supabase/Postgres, TypeScript. Может добавить AI-фичи в продукт.

**Зарплата (РФ, нетто, удалёнка):**
- Junior: 70-130K руб/мес
- Middle: 130-250K руб/мес
- Senior: 250-450K руб/мес
- Lead: 450-650K руб/мес

**Что нужно из курса:**
- Проекты #1-3 в портфолио (образовательная платформа, дашборд, Telegram-бот)
- Next.js 16 + Supabase + Tailwind v4
- TypeScript на уровне middle (strict mode, типизация)
- Понимание RLS, миграций, деплоя

**Где есть вакансии:** продуктовые стартапы, tech-компании, агентства

**Замечание:** На fullstack без AI-фокуса попасть сложнее (много конкурентов с CS-образованием). С AI-уклоном — окно возможностей.

---

#### 4. ML-инженер (Machine Learning Engineer)

**Что делает:** Работает с моделями (обучение, fine-tuning, deployment). В отличие от AI-инженера — больше про сами модели, меньше про интеграцию.

**Зарплата (РФ, нетто, удалёнка):**
- Junior: 100-180K руб/мес
- Middle: 180-350K руб/мес
- Senior: 350-600K руб/мес
- Lead: 600K-1M руб/мес

**Что нужно из курса:**
- Базы AI/LLM, понимание Tool Use, RAG
- **Дополнительно потребуется:** Python (PyTorch/TensorFlow), классический ML, статистика
- Курс даст 60-70% базы, остальное — самообучение (1-2 месяца)

**Где есть вакансии:** R&D-отделы Яндекса, Сбера, VK, Тинькофф, AI-стартапы

**Замечание:** Самая высокооплачиваемая ниша, но требует дополнительного обучения после курса. Подходит, если есть техническое образование.

---

#### 5. Бизнес-аналитик в IT / AI Product Manager

**Что делает:** Переводит бизнес-требования в техзадания. Проектирует продукты. Работает на стыке бизнеса и разработки. С AI-знаниями — защищает идеи AI-фич перед менеджментом.

**Зарплата (РФ, нетто, удалёнка):**
- Junior: 80-140K руб/мес
- Middle: 140-250K руб/мес
- Senior: 250-400K руб/мес
- Lead: 400-600K руб/мес

**Что нужно из курса:**
- Spec-First методология (это и есть работа аналитика!)
- Шаблоны спецификаций (SPEC_TEMPLATE, FEATURE_SPEC_TEMPLATE)
- Понимание стека (чтобы не писать невыполнимое ТЗ)
- Опыт работы с заказчиками (Discovery Sprint)

**Где есть вакансии:** IT-консалтинг, продуктовые компании, интеграторы

**Замечание:** Самый низкий порог входа из всех 5 позиций. Курс даёт всё необходимое.

### 30-60-90 план: Трудоустройство

#### Дни 1-30: «Подготовка и первые отклики»

**Цель:** Готовое CV, портфолио, 50+ откликов отправлено.

| Неделя | Задачи | KPI |

### Важные замечания по трудоустройству

**Что работодатели ценят больше всего:**
1. **Реальные кейсы** — не учебные TODO-приложения, а проекты с реальной бизнес-логикой (как из курса)
2. **GitHub с историей коммитов** — видно, как работает мозг, как пишется код
3. **Понимание production** — деплой, мониторинг, безопасность, RLS (это редкость у джунов!)
4. **Soft skills** — особенно коммуникация на интервью

**Чем выпускник курса AI-Архитектор уникален:**
- **Spec-First мышление** — большинство джунов не умеют писать спецификации
- **Production-grade проекты в портфолио** — не toy-проекты
- **Опыт с современным стеком** — Next.js 16, Tailwind v4, Supabase RLS
- **Понимание AI-интеграций** — это редкий навык, за который доплачивают

**Подводные камни:**
- "Нет опыта 3 года" — фильтр HR. Решение: откликаться напрямую CTO, через рекомендации, на стартапы
- Технические интервью могут спрашивать алгоритмы — подготовьтесь по LeetCode (easy/medium)
- System design — научитесь чертить архитектуру (Excalidraw, draw.io)

## Комбинированные стратегии (рекомендуемые)

### Стратегия А: Предпринимательский путь
Для тех, кто готов рисковать ради безлимитного потолка:
```
Месяц 1-3: Фриланс (быстрые деньги + кейсы + понимание рынка)
    |
    v
Месяц 3-6: Фриланс + запуск SaaS (используешь кейсы фриланса для идей)
    |
    v
Месяц 6-12: SaaS + фриланс на минимуме (SaaS растёт, фриланс даёт cash flow)
    |
    v
Месяц 12+: Полный фокус на SaaS или агентство
```

### Стратегия Б: Стабильный путь с боковыми проектами
Для тех, кто хочет стабильности + дополнительный доход:
```
Месяц 1-2: Поиск работы (Путь 4) + параллельно 1 фриланс-проект для портфолио
    |
    v
Месяц 2-6: In-house работа (стабильная зарплата) + 1-2 фриланс-проекта в выходные
    |
    v
Месяц 6-12: In-house + накопление подушки + изучение бизнес-стороны компании
    |
    v
Месяц 12+: Решение — оставаться/уходить во фриланс или запускать SaaS с подушкой
```

**Главное преимущество Стратегии Б:** ноль риска. Зарплата обеспечивает базу, фриланс даёт опыт работы с клиентами, через год — осознанный выбор пути.


```
  ↓ Фрилансер / Агентство / SaaS / Комбинированный

  ↓ Конкретно: "200K/мес", "5 платящих пользователей", "команда 2 человека"

  ↓ Загрузите:
  • Этот справочник (10-57)
  • Описание статуса + путь + цель
  
ШАГ 5: Промпт:
  "Сгенерируй мою персональную дорожную карту на 90 дней.
```
